# 验收与限制

验收结论区分自动化、隔离环境和用户确认的实际环境，不将构建成功、页面可访问或模拟测试等同于全部生产验收。以下结论汇总已有验证，不表示每个提交重新完成了全部验收。

## 自动化和隔离验证

| 领域 | 已有覆盖 | 边界 |
| ---- | ---- | ---- |
| 工程交付 | 前端类型检查／构建、Go 测试／vet、单 EXE 安装与重启冒烟 | 真实 SVN 测试需设置 SVN_BIN，否则明确跳过 |
| 权限与账号 | 越权、撤权、旧管理员请求、本地用户删除清理及事务回滚、最后管理员／Owners 保护、会话失效、Origin／CSRF | 确定性并发边界注入不等于真实多进程压力验收；未删除真实用户作测试 |
| LDAP | 模拟目录、自签名 LDAPS／StartTLS、单源证书选项、分页／空结果、身份冲突、清理确认、cron 与历史恢复 | 隔离目录不能代替企业 AD／LDAP 全部配置 |
| SVN 与恢复 | 一次性真实 SVN 仓库的迁入、镜像、快速转换及失败回滚、进度、游标分页、路径保护、任务重启恢复 | file 源不能代替真实 HTTP/HTTPS 认证、证书和服务端权限 |
| 通知 | 模拟发送器／传输、加签、Outbox、重试、配置取消、仅失败重发、保留清理 | 自动化不向真实钉钉群发送；尚无真实群投递验收结论 |
| 前端 | 模板／状态渲染、分页、时间格式化及桌面／窄屏检查 | 模拟视口和 HTTP 检查不自动等于真实设备验收 |

## 用户确认的实际环境

| 项目 | 结论 |
| ---- | ---- |
| 干净 Windows、Server 2016 与 Windows 服务注册 | 用户确认实际环境验收通过 |
| 跨磁盘本地迁移 | 用户确认真实跨磁盘迁移验证通过 |
| 用户／组织／通知页面视觉交互及趋势慢网、焦点、真实触摸 | 用户确认已验证通过；该确认不自动覆盖后续所有界面改动 |
| 真实 LDAP | 已连通并满足当前使用需求；严格 TLS、分页、停用及稳定身份专项不再推进，未逐项声明通过 |
| 真实 HTTP/HTTPS SVN | 用户已验证镜像、认证和证书，满足当前使用需求；首次／增量、全历史权限及中断专项未逐项声明通过 |

## 暂缓和已知限制

真实断电和磁盘满故障验收暂缓，未记为通过。Windows 符号链接创建用例受账户权限影响可能跳过，应以实际测试输出为准；目录联接保护已有隔离验证。

快速转换只验证身份与镜像配置，不能证明全部历史内容、属性和复制来源一致。服务端读取权限可能隐藏历史，客户端不能证明远端账号具有完整读取权限。必须由操作者确认同源、无独立修改和完整读取权限。

通知超时或重启可能重复送达；只读浏览和下载受命令输出上限约束。恢复失败应保留日志和所有副本，不手工清库或删除唯一副本。操作约束及恢复步骤见[部署指南](deployment.md)和[架构与恢复](architecture.md)。
