# 功能与权限

## 产品边界

SVNova 管理组织内的 SVN 仓库浏览和远端镜像。Windows x64 单 EXE 内嵌模板、前端和命令行工具，数据库为 SQLite，界面为中文。程序不托管 SVN 协议，不提供 Git、Issue／PR、匿名或路径级权限、目录打包下载、独立归档备份恢复产品。

## 账号与授权

| 角色 | 能力 |
| ---- | ---- |
| 全站管理员 | 站点设置、用户及 LDAP 管理、创建组织、本地迁入，并可管理全部组织和仓库 |
| 组织 Owners | 管理本组织资料、成员、团队及仓库；远端迁移、同步、镜像设置、快速转换和移除 |
| 普通成员 | 通过团队获得整个仓库的浏览、下载和任务记录访问权；组织成员身份本身不授予全部仓库 |

授权在后端执行，停用、退出或撤权后不能继续访问。内置 Owners 团队不能作为普通团队修改授权；成员变更、退出及账号清理保护最后的 Owners，账号清理还保护最后活跃管理员。

本地用户由管理员创建，可自行修改密码，成功后全部会话失效。管理员可在编辑页输入用户名确认删除本地账号；事务删除账号、会话及组织／团队成员关系，保留仓库、组织、团队和历史。禁止删除当前操作账号、最后活跃管理员及组织最后活跃 Owners。LDAP 用户不在此入口单独删除。用户编辑页始终显示管理员与启用选项，本人选项勾选并禁用，以隐藏字段保留提交值；删除区域始终显示，LDAP、本人、最后活跃管理员及最后活跃 Owners 的删除入口禁用并展示原因。页面与后端事务使用相同删除保护规则，提交时重新校验。本人可以访问自己的主页；查看其他用户主页和管理员用户详情需要管理员权限。

组织为私有组织，创建者加入 Owners。组织可维护全名、邮箱、描述、网站和地区；删除组织需要名称确认且组织内无任何仓库。团队支持名称、描述、成员及指定仓库授权。

## LDAP

系统只保存一份 LDAP 配置，不提供认证源列表、新增或切换。支持 LDAPS 和强制 StartTLS，默认验证证书；管理员可显式忽略验证。新建 LDAP 用户（同步或首次登录创建）默认未启用，须由管理员在用户管理中启用后才能登录；既有账号状态不批量变更。LDAP 用户绑定稳定身份；同步遇同名本地账号跳过并记录，登录不能接管本地账号。

映射用户名、稳定身份、显示名称和邮箱；邮箱属性为空时不更新。过滤器支持 `%s`、`%[1]s`；登录替换转义用户名，同步替换 `*`。分页默认开启、大小 500，可配置 1–1000。关闭 LDAP 认证禁止 LDAP 登录和同步；关闭用户同步不影响登录；成功空结果默认保留用户，只有显式启用对应选项才允许停用全部 LDAP 用户。同步不自动授予组织或团队权限。

修改已有 LDAP 配置，须预览并确认相关 LDAP 用户清理。保留本地用户、组织、团队、仓库和历史；最后活跃管理员／Owners 保护可能拒绝操作。配置未变化不清理。同步历史记录操作者、触发方式、统计和安全错误分类。

同步计划使用北京时间五字段 cron，默认 `0 0 * * *`。锁忙时等待，停用认证／同步或修改表达式取消尚未开始的旧任务；停机错过不补跑。无下一次执行时间的表达式不会触发任务。旧 HH:MM 值需重新保存为 cron。

## 仓库与镜像

- 本地迁入仅管理员可用，源必须是服务器可访问的已停止 SVN 仓库，不能使用工作副本。同盘移动，跨盘复制并校验后才删除源。
- 远端迁移仅支持 HTTP/HTTPS 完整仓库根地址，创建镜像。默认同步间隔 8 小时，最小 10 分钟，0 关闭自动同步；支持手动同步。
- 同步检查远端 UUID 和修订回退，异常停止并保留本地内容。已有成功仓库的后续同步失败不会删除其可浏览历史；列表的最近成功时间不代表最近尝试成功。
- 本地转镜像仅支持快速转换，保留路径和历史。检查身份、修订、r0 属性、钩子和镜像配置，不逐修订比对历史内容，也不额外全库 verify。相同 UUID 不能证明历史一致，必须自行确认同源且历史未独立修改。
- 仓库移除默认保留文件；永久删除需名称确认，检查活动任务、受管根边界和链接。

文件页使用面包屑保持指定修订，支持文本预览及单文件原字节下载。预览支持 UTF-8、GBK／GB18030 及带 BOM 的 UTF-16；不修改仓库字节，不提供差异功能。修订历史按修订游标每页 10 条，时间显示北京时间。主表显示修订号、动作字符汇总、作者、时间和单行截断消息；主表无提交消息时留空。各行可独立展开完整消息及路径、动作、复制来源路径和来源修订四列详情，展开区整体留出主表详情列宽度，不显示分节标题；主表及详情动作使用 SVN 字符 A／M／D／R，分别表示新增／修改／删除／替换，提供中文悬停提示；动作及来源修订列保持紧凑，为路径列留出宽度；修订条目表格使用 12px 小字号，减少长路径换行；无复制来源的路径与修订单元格留空。详情随当前页加载，展示该修订全部变更路径。

文件大小为指定修订下的文件长度，目录不递归汇总。仓库大小为完整受管目录的普通文件长度之和，包含历史和元数据，不等于磁盘分配空间；后台缓存，未知显示待统计。成功迁移／同步／转换后刷新，存量就绪仓库在空闲时补算。显示采用 B／KiB／MiB／GiB。

## 活动、界面与通知

首页热力图和动态统计当前可读仓库的迁移／同步执行，不把 SVN 作者映射成站点用户。仓库列表及首页活动每页 10 条。`/activity` 独立展示日活动趋势，默认镜像同步、近 30 天，可切换活动类型及近 7／30／90 天，按北京时间聚合。趋势图使用按需加载的 ECharts 堆积柱状图与原生状态图例，底部滑块支持日期缩放和平移，图表及滑块左右各预留 80px 以完整显示两端日期，不启用图内缩放；轮询保留图例及缩放窗口，切换筛选重置窗口。标题栏使用浅灰主题背景，筛选区在 768px 及以上各占一半，窄屏分行，上下内边距均为 16px，单选标签清除全局下边距。头像在本地生成，不调用外部头像服务。首页活动左侧显示链接到组织首页的 40px 组织头像，右侧依次显示完整北京时间、任务类型图标、彩色状态图标及任务记录入口图标；正文首行展示组织、仓库短名称及任务类型（触发方式），下方展示执行结果概要，不显示任务与执行编号，不额外读取 SVN 修订日志。

钉钉通知为全站单个加签机器人，仅管理员配置，默认总开关关闭。SVN／LDAP 分类开关默认开启，无变化默认不通知；SVN 可选择仅失败。不支持按仓库排除。配置页提供投递记录入口，只有失败投递可手动重发到当前机器人。

只发送支持的结束事件：首次镜像迁移、镜像同步和 LDAP 同步；本地迁入和本地转镜像本身不产生 SVN 通知。转换后排队的首次镜像同步按通知规则处理。保存配置不发送，测试消息需管理员主动操作；不补发既有历史。超时或重启后可能重复送达，不承诺恰好一次。

页面列表：管理员用户、通知投递、LDAP 同步历史和仓库任务记录每页 20 条，其余已分页列表每页 10 条。LDAP 历史使用共用完整分页，首页仓库使用五格紧凑分页；修订历史保留游标导航。

任务中心 `/tasks` 集中展示当前有权读取仓库的 SVN 任务，默认全部、编号倒序，每页 20 条，支持按任务编号、组织名或仓库名搜索，以及类型、状态两个独立下拉筛选。只查看及跳转，不提供中心重试；LDAP 历史保留管理员入口。重试沿用任务编号，列表不按执行次数重复展示。

任务中心编号与仓库分列，组织名和仓库名分别链接对应页面，触发方式和操作人分列；列表不展示阶段／进度，新增结果概要列，操作列提供查看记录图标。任务页采用标题计数、搜索筛选栏和贴边表格的连续卡片；不显示组织／仓库下拉、排序或重置按钮。关键词回车／搜索按钮提交，类型与状态单选后立即筛选并回到第一页；分页保留条件，轮询同步更新标题计数。任务、用户管理及组织管理的工具栏统一四周 16px 内边距，窄屏搜索框独占一行。

仓库设置分为基本设置、镜像设置、危险操作三个菜单页；本地仓库的镜像页提供转换入口。三个页面均要求管理权限。

前端 checkbox 统一使用原生复选框、主题定义的 14px 尺寸和 8px 文字间距，文字换行时按首行对齐；内联与普通表单保持一致。

活动、任务中心及仓库任务记录统一展示执行结果概要。同步成功显示新增修订数及起止修订号，无新增时显示当前修订；迁移显示最终修订，转换保留未逐修订比对提示。活动使用各次执行快照，任务列表使用最新执行；重试排队和运行中不显示旧结果。旧记录缺少可靠快照时不补算修订数。

带文字按钮统一为常规 14px／38px、标题栏及列表 12px／32px，窄屏尺寸不变并允许文字换行。主要提交操作蓝底白字，辅助操作浅灰底，危险入口红色描边，危险确认红底白字（包括 negative）。创建、保存及确认／取消统一纯文字；同步、重试、发送和任务记录保留 16px 图标及 8px 间距。同步采用 sync，重试采用 issue-reopened；首页镜像同步类型保留 sync，进行中状态采用 hourglass。纯图标按钮桌面点击区域 32px、窄屏 40px；请求期间禁用同步按钮并旋转 sync 图标，刷新导航提供相同反馈，遵守减少动态效果设置。

镜像设置操作列为图标加文字按钮预留宽度；镜像地址可折行，窄屏沿用表格堆叠布局，避免按钮溢出及强制表格最小宽度导致的水平滚动。

操作限制和禁用原因采用前置 Octicons info 图标，普通原因说明在表单内外统一使用灰色，保留可读文字及信息／告警框原有颜色；覆盖用户权限／删除保护、LDAP 同步及密码管理、Owners 成员／仓库规则、镜像同步／转换限制和通知测试配置前置条件。Owners 保护原因在团队卡片内容区或成员列表的独立说明行展示，避免挤入标题统计和操作按钮区，不仅依赖悬停提示。

全部列表搜索框及团队成员候选框提供统一的输入框内清除按钮，仅有内容时显示。列表清空关键词后立即提交并回到第一页，保留其他筛选与排序；成员候选只清空输入并更新候选，不提交添加操作。清除后恢复输入焦点，隐藏浏览器重复的原生清除图标，不改变搜索行高度。

仓库任务记录分为统计卡片、任务趋势图和分页表格。统计覆盖全部历史任务，重试按最新执行计一次；成功率为成功／已结束（成功、失败、中断），排队和执行中不计分母。版本跨度由最早可靠基线至最新成功修订；迁移／转换以最终修订为基线，同步以起始修订为基线。累计新增仅累加成功同步的修订差，缺失快照的旧记录不补算。ECharts 使用北京时间任务开始时间轴，左轴为版本号阶梯折线，右轴为耗时普通折线，两条线同时展示，图例固定为“版本号／耗时”。不绘制新增修订图形、类型圆点或独立事件窄带，也不提供指标切换。镜像迁移／本地迁移／转换镜像分别以紫色实线／蓝色虚线／橙色点线贯穿绘图区；失败任务统一用红色竖线替代原类型线，缺少修订或耗时快照时仍保留失败标记。鼠标在绘图区移动时显示竖向参考线并吸附最近可见任务时间，同时间任务合并展示；全部可见任务均参与时间吸附，包括运行中或缺少修订／耗时快照的同步任务，不绘制虚假指标；详情继续显示本次新增修订数，累计新增卡片不变。

任务类型默认全选，在标题下独立栏以复选项展示；筛选控制事件竖线、两条折线及提示内容，切换类型按可见任务重算坐标并重置滑块。轮询、图例切换及尺寸变化保留缩放窗口，不改变卡片统计。图形共用时间坐标，版本号标题与左轴刻度文字右对齐，耗时标题与右轴刻度文字左对齐。绘图区和滑块按容器宽度左右各留 128px（至少 768px）、88px（480–767px）或 56px（小于 480px），窄容器日期／时间标签分行。未知修订和耗时不伪造数据，进行中不绘制最终耗时。

仓库任务表按编号倒序每页 20 条，结束时间紧跟开始时间，结果不再包含完成时间；单任务入口仍为单任务详情。活动任务每 5 秒刷新，否则每 30 秒刷新；临时失败保留数据并提示，撤权清空数据并停止刷新。
