# 架构与恢复

## 分层和运行模型

| 层 | 职责 |
| ---- | ---- |
| 入口与 Windows 服务 | 固定工作路径、实例锁、日志、内嵌工具释放、HTTP 生命周期及后台任务退出 |
| `services/app` | 路由、会话／CSRF、权限、表单与 API、Go 模板及后台服务组装 |
| `models` | SQLite／xorm 模型、schema 迁移、授权查询与事务约束 |
| `services/directory` | LDAP 认证、同步、配置清理、cron 调度和历史 |
| `services/tasks`、`services/svn`、`services/storage` | 持久任务、全局仓库互斥、受限 SVN 子进程及安全路径操作 |
| `services/notifications` | 事务 Outbox、加签消息、重试、投递历史和保留清理 |
| 模板与前端 | Go 模板、TypeScript 局部初始化、Vue 图表、Gitea 浅色变量及 Octicons |

单实例持有工作目录锁。SQLite 使用 WAL，模型层单连接并在关键事务先取得写锁，避免删除／撤权与旧请求之间产生孤立授权。不能通过仅隐藏按钮替代后端检查。

仓库任务全局串行，迁移、镜像同步、转换、仓库设置及大小统计共享互斥。另一个仓库有操作时，设置保存也可能返回冲突。LDAP 采用单例配置与稳定身份绑定，有独立同步锁，钉钉有独立发送 worker，不因通知失败重跑仓库或目录同步。

## 任务与进度

完整调度流程、状态跃迁图和正常停止／异常退出后的区别见[任务调度、状态与停止恢复](task-scheduling.md)。调度行为变更时同步维护该专题。

任务持久记录类型、状态、阶段和当前尝试时间；每次实际执行另建 task_execution，重试不覆盖历史执行结果。浏览器关闭不中断后台任务。迁移状态通过认证后的串行 2 秒轮询更新，恢复策略由任务类型决定。

本地迁入显示检查、源校验、移动／复制、目标校验、身份核对和源清理。verify 计数包含 r0，总数为 HEAD+1；元数据阶段没有可计算百分比，使用不定进度并显示阶段耗时和最后进展时间。最后进展时间不是进程心跳，不能据此断言进程卡死。

镜像同步检查远端身份，执行初始化／内容同步及修订属性同步，再持久化结果。属性阶段按 svnsync 的实际输出记录最后处理修订，包含 r0；没有实际输出时不沿用内容同步的 rHEAD/HEAD。进度回调节流写库，消费输出但不累计无限日志。

## 本地迁入恢复

同盘迁入先校验源，再重命名到受管路径；跨盘先 hotcopy 到 staging，校验副本并核对身份后发布，持久化 published 阶段后清理源。中断时保留可用副本和阶段信息；重启对普通 running 任务重新排队，按持久阶段复查，不保证所有阶段续传。

已有目标或 staging 冲突时拒绝覆盖；发布后清理失败仍保留目标，需要核查源和任务状态。不得只凭错误页面删除任一目录。仓库目录按组织／仓库命名，旧路径迁移使用 repository_path_move 恢复记录，不能越过路径边界或链接检查。

## 快速转换恢复

转换由管理员或 Owners 提交持久后台任务，任务候选凭据加密且不通过 JSON 返回。执行开始及提交配置前重新检查操作者权限和仓库身份／状态，拒绝重复转换及冲突修改。

身份检查包含受管路径、本地状态、远端根地址、UUID、修订不落后、r0 属性、活动钩子及已有镜像元数据。恢复快照先于受控钩子及 `svnsync initialize --allow-non-empty` 写入。初始化后复核镜像元数据和两端身份；镜像配置、转换成功记录、首次同步入队及恢复日志删除在同一事务提交。

整体超时从实际执行开始计时，不含排队，默认 24 小时；命令受剩余整体时间约束。失败／超时用独立有界上下文恢复 r0 和新增受控钩子，保留仓库数据。恢复失败保留日志并阻止后续修改；启动先恢复日志，失败则拒绝正常启动。恢复完成后遗留 running 转换标记失败／中断，必须手动重试并重新检查，不承诺断点续转。

快速检查没有逐修订内容、属性及复制来源比对，不能证明两端历史一致。

## 事务与安全边界

- 同步最终结果和通知入队在同一数据库事务完成；通知投递失败独立记录。发送中重启视为不确定投递，允许有限重试，可能重复送达。
- LDAP 批量用户更新和成功历史原子提交；失败回滚用户变更并记录安全失败分类。遗留运行记录标为中断，不在启动时自动补做 LDAP 同步。
- 本地用户删除重新检查操作者、目标和最后活跃管理员／Owners，原子清理会话、团队及组织关系。LDAP 配置清理的确认令牌绑定配置和受影响关系，过期或陈旧则拒绝。
- 子进程使用参数数组，不拼接 shell。普通命令默认 30 分钟；本地 verify／hotcopy 默认每命令 24 小时，转换使用整体可配置期限。输出和错误长度有界，关闭服务会取消子进程并等待后台退出。
- 受管目录限制在本机磁盘，拒绝不安全的符号链接、目录联接及 reparse point。密钥和凭据文件不进入源码仓库。

## 大小、活动与缓存

仓库大小扫描共享仓库锁，每次最多 30 秒。成功任务后刷新；无排队任务时每 10 秒至多补算一个未知大小的 ready 仓库，未知统计失败至少 5 分钟后再试。失败保留旧成功值，不能改变业务任务结果；页面读取缓存而不扫描磁盘。

首页活动来自 task_execution，旧任务仅在没有执行记录时兜底一次；旧 revision_event／activity_index 表保留兼容，不再驱动首页。所有活动与趋势按当前仓库权限过滤。头像按种子和尺寸本地生成并有限缓存，请求先检查权限，再处理私有缓存复验。

任务中心在 SQL 中联合仓库、组织并以成员／Owners／团队授权 EXISTS 过滤，再计数和分页；使用现有任务主键及仓库索引，无新增 schema。任务 Started 是当前尝试开始时间，不能当作创建时间，中心按任务 ID 倒序。当前页有活动任务时串行 5 秒刷新，隐藏暂停，可见时重新查询；完成后停止，刷新失败清除过期列表并提示重新刷新。
